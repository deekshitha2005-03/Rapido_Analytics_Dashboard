# 🚖 Rapido Ride Analytics Dashboard | Power BI

## 📌 Project Overview

The **Rapido Ride Analytics Dashboard** is an interactive Business Intelligence solution developed using **Microsoft Power BI** to analyze ride booking data and provide actionable insights into business performance.

The dashboard enables stakeholders to monitor operational efficiency, customer behavior, booking trends, cancellations, payment preferences, and revenue performance through an intuitive and interactive interface.

A unique feature of this project is the implementation of **Power BI Bookmarks and Navigation Buttons**, allowing users to switch between multiple dashboards within a single report page for a seamless user experience.

---

# 🎯 Business Problem

Ride-hailing companies generate massive amounts of operational data every day. Without proper visualization, it becomes difficult to identify:

* Operational bottlenecks
* Customer cancellation patterns
* Driver cancellation reasons
* Revenue-generating locations
* Vehicle performance
* Customer preferences
* Business growth opportunities

This dashboard transforms raw booking data into meaningful business insights that help improve decision-making.
